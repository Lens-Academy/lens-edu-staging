# Lens: Four Evidence Streams, One Claim
id:: c0b4eb85-03ca-4b7c-affe-842866e24322
#### Text
content::
No evidence stream verifies "AI safety" in general. Each tests a narrower claim.

- **Hardware:** chip identity, location, topology, authorization, and use.
- **Cloud:** customer identity, workload records, resource allocation, and provider attestations.
- **Intelligence:** procurement, construction, power, network, imagery, and other signatures visible without permission.
- **Human and institutional:** declarations, audits, inspections, insider reports, adjudication, and enforcement.

Compare mechanisms on four axes: claim tested, evidence produced, implementation requirements, and principal failure mode. Add a fifth when adversaries are involved: what secrets the mechanism exposes. Verifiability that destroys confidentiality may be politically unusable or create a new security risk.

This module uses Lens's current technical reading set to cover method taxonomies, near-term feasibility, hardware-enabled guarantees, and inference evidence. XLab's live alpha includes richer cloud, intelligence, and human-layer exercises, available from [its source curriculum](https://aisafetytracks.com/verification/landing).
