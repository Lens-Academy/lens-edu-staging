Unit 5 looks at how people argued about that real case.

\## An open-weight model

So far the developer runs the model on its own servers. Some developers instead publish a model's weights, so anyone can download, run and change the model. This is called an open-weight model. Once the weights are public, the developer cannot monitor how the copies are used or take them back.[^cite-casper-2026]

[^cite-casper-2026]: Stephen Casper et al. (2026), *Open Technical Problems in Open-Weight AI Model Risk Management*, [OpenReview](https://openreview.net/pdf/a086fd843c7697bd9662f11f1a34369cd2703fcb.pdf)
