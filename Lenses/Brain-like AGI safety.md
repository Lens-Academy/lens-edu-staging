#### Text
content::
This approach starts from a specific premise: that the AGI we should worry about will **itself be brain-like** — an actor-critic reinforcement learner with a from-scratch, cortex-like **Learning Subsystem** steered by an innate, brainstem/hypothalamus-like **Steering Subsystem** that supplies the reward signal. Steven Byrnes argues such a system has *dangerous, radically nonhuman motivations by default*, and that the fix is to reverse-engineer the brain's innate steering / social-instinct circuitry so we can install good motivations on purpose. Read his framing of the problem.

#### Text
content::
Three things to carry away:

- **Two subsystems.** A from-scratch Learning Subsystem (knowledge/skills via experience) + an innate Steering Subsystem (reward/motivation). Together: an actor-critic RL agent.
- **Dangerous by default.** A capable, autonomous, goal-pursuing brain-like AGI tends toward misaligned motivations unless deliberately steered — and could cause catastrophe without sci-fi superweapons.
- **The fix.** Reverse-engineer the brain's reward/steering system so beneficial values are *foundational*, not bolted on afterward.

Note how this differs from the **BCI-type solutions** covered in the rest of this module: those change the *human* side of the equation; this approach keeps the focus on the AI, but assumes it is brain-like and aligns it on those terms.
