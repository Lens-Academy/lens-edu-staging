title: "Why Would AI Want to do Bad Things? Instrumental Convergence"
tldr: >-
  You can predict that a stranger will accept money without knowing what he wants, because money helps with almost any goal. In the same way, an AI with almost any goal has reasons to avoid being shut down, keep its goals, improve itself and gather resources.
summary_for_tutor: >-
  Rob Miles explains instrumental convergence. Assuming only that an AGI is an agent with goals, some instrumental goals help with almost any terminal goal, so we can predict them without knowing the terminal goal, as we can predict that a stranger will take money. The convergent instrumental goals he names are self-preservation, goal preservation, self-improvement (including more computing power) and acquiring resources (matter and energy). Self-preservation is not a terminal goal: a paperclip maximizer resists being switched off because that means fewer paperclips, but it would accept being wiped and replaced by a better paperclip maker. It would resist having its goal changed to stamps, like the man who wants to cure cancer refusing a pill that would make him want to collect stamps. The question asks the student to apply this to a scheduling AI.

content::
A hospital runs an advanced AI agent whose only goal is to keep its appointment schedule as efficient as possible. It understands that it runs on the hospital's servers and that staff can switch it off. Nobody gave it any goal about protecting itself. An engineer says: "It has no survival instinct, so it has no reason to resist being switched off."

1. Using Miles's reasoning, why might the agent still try to stop staff from switching it off?
2. The hospital later plans to switch it off and replace it with a new system that schedules even more efficiently and has the same goal, and the agent knows this. Using the video, would the agent resist this too? Why?

assessment-instructions:: Score out of 100. The video's idea: some instrumental goals help with almost any terminal goal, so an agent that understands its situation tends to pursue them whatever its terminal goal is. Self-preservation is one: the agent need not value existing for its own sake, but if it is switched off it cannot pursue its goal, so worlds where it is switched off score worse on its goal. Because the reason is instrumental, the agent only resists what makes its goal less likely to be met. The video's example: a paperclip maximizer would accept being wiped and replaced by a better paperclip maker, because that leads to more paperclips.
50: Step 1. Says that being switched off would stop the agent from making the schedule efficient, so avoiding shutdown helps its goal, even though it does not value its own existence. Mentioning that this holds for almost any goal (a convergent instrumental goal) is welcome but not required.
50: Step 2. Says it would probably not resist, because the replacement has the same goal and serves it better, so being replaced makes the schedule more efficient, which is all the agent cares about. Cap this step at 15 if the answer says the agent would resist because it wants to survive or exist.

If the replacement has the same goal and does it better, being replaced makes the schedule more efficient, so it has no reason to resist. Like the paperclip maker in the video, it is fine being wiped for a better version."
