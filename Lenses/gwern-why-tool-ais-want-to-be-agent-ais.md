Gwern argues this equilibrium can't hold: agent AIs that act on their own will out-compete tool AIs economically and, more surprisingly, will be smarter too, because the same agency that picks actions also picks what to learn and how."
summary_for_tutor: "Gwern's argument against 'Tool AI' (systems confined to computation and prediction with humans executing all actions, e.g. Holden Karnofsky's Google Maps analogy) as a solution to AI risk. Two core claims: (1) Economic, that agent AIs which act autonomously out-compete tool AIs because human-in-the-loop oversight becomes the bottleneck (Amdahl's law), as illustrated by advanced chess and recommender systems shifting to reinforcement learning. (2) Intelligence and learning, that agency itself improves inference and learning, since the same RL machinery that selects actions can also select what data to learn from, how long to train, how to self-optimize, and how to use external resources; 'all problems are reinforcement-learning problems.' Concludes Tool AI is an unstable equilibrium, inferior on both competitiveness and capability, so tool AIs tend to become agent AIs. Also reviews related Oracle AI issues (Bostrom) and Tool AI critiques (Armstrong)."
