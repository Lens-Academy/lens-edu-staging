#### Text
content::
This course covers what everyone working in AI safety should know. People start it knowing very different things, so it does not ask everyone to read the same pages. It gives you a list of things you should be able to do, material to learn each one, and questions to check yourself. You work on what you cannot do yet.

\## Units and levels

The course is split into units. Each unit ends with a group meeting.

A unit has up to three levels on the same topic:

- **Level 1** is the core of the unit and carries the unit's name. Do it first.
- **Level 2** goes deeper into the same topic.
- **Level 3** covers the rest of the unit.

The levels build on each other: Level 2 assumes Level 1, and Level 3 assumes Level 2. If you can already do what a level asks, skip it and move on to the next one. How far you get in a unit depends on the time you have that week.

\## Learning outcomes

A level is a list of learning outcomes. A learning outcome is one thing you should be able to do, for example "Explain what scheming is". Each one has its own page with:

- the outcome in one sentence
- a small map of the outcomes it builds on and the outcomes that build on it
- lenses that teach it
- questions to test yourself

The stars show how much an outcome matters in this course. When time is short, do the three-star outcomes first.

The time shown for an outcome is the worst case: reading every lens and answering one question. If you know the topic already, it takes far less.

\## Active recall

After you answer a question, you pick when you want to be asked again: Again, Hard, Good or Easy. Each button shows how long the wait is. When that time is up, the outcome comes back on the Active recall page of the course with one of its questions. Each time you pick Good or Easy, the next wait gets longer.

If you are sure you know an outcome, switch on "Exclude from active recall" on its page. You can switch it off again later.
