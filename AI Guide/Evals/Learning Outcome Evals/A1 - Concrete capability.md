# A1 — Concrete capability

**Binary question:** Does the `learning-outcome:` statement name an observable capability, pinned precisely enough that you can tell what would count as demonstrating it?

## Pass boundary

The statement describes something the learner *does* — explain, distinguish, produce, apply, decompose, state — with the object of that action pinned: not just a topic, but what about the topic must be explained, distinguished, or produced. The test: reading only the statement, can you imagine the test question and recognize a passing answer? Verbs like "understand", "know", "be aware of", "appreciate", "be familiar with", and "reason about" fail this test — you cannot observe them.

## Does NOT fail for

- Length or multi-clause statements, as long as the clauses elaborate one capability.
- Situated phrasing ("Given an unfamiliar case, the learner can…").
- Recall-flavored verbs (state, name, identify) when the object is specific — recall can be a legitimate capability.

## Fail examples (from the corpus)

- "Understand the basic decomposition of risks into AI misalignment, misuse, power grabs, and others" (*Decomposing AI risks*) — human ruling: "'Understand' is too vague."
- "Be aware of discussions on whether AI systems develop goals and understand the basic arguments for instrumental convergence" (*Goals and instrumental convergence*) — human ruling: "Too vague. And seems to be two LOs at once."
- "Reason about training stories and outer and inner (mis)alignment, challenges to these notions, and the relationship to inductive biases" (*Training stories and outer–inner alignment*) — a topic list with no observable action pinned.

## Pass examples (from the corpus)

- "Given an unfamiliar question with no available reference class of its own, break it into sub-questions each of which has a reference class or a measurable quantity, state for each sub-question what evidence would settle it, combine them into an estimate, and name the sub-question whose error dominates the result." (*Decomposing an unanswerable question*) — long, but every clause is an observable action.
- "Distinguish hostile from indifferent AI: explain why the core danger from superintelligent AI is not that it would be hostile toward humans, but that it would be indifferent to human values while pursuing its own goals: indifference is sufficient for extinction" (*Hostile vs. indifferent AI*) — the mechanism the learner must articulate is pinned.
